Flash-Flags v1.3.4 - Stable Help, Reset Reloads the Config
=========================================================

Release Date: 2026-11-24
Type: Fix

FIXED
-----
- Help, PrintUsage and VisitAll follow declaration order. They walked
  the flag map, so flags and groups came out in a different order on
  every run. Ungrouped flags come first, then each group in the order
  of its first flag. Validation reports errors in the same order, so
  the first error of a Parse no longer changes between runs. A flag
  declared twice keeps its first position.

- FlagSet.Reset now lets the next Parse load the config file again, as
  its documentation promises ("as if Parse() was never called").

  LoadConfig runs once per load and Reset left the file marked as
  loaded, so the next Parse skipped it: every flag the command line did
  not set fell back to its default instead of the config value. Found
  through examples/config, whose step 3 printed the defaults labelled
  "from config".

- FlagSet.Reset also clears the operands of the previous Parse: Args()
  is empty until the next Parse.

CHANGED
-------
- Two dead branches removed from the parser: processArgument's fallback
  for an argument neither short nor long, which parseArguments never
  sends (isLongFlag goes with it), and a bool branch in
  parseShortFlagWithEquals identical to the general one.

- examples/config: the priority list includes environment variables,
  and auto-discovery searches only the directories added with
  AddConfigPath (the list of default directories was removed earlier).

- New examples/server: flags in groups, a validator, a config file and
  SERVER_* environment variables, printing where each value came from.

- README: a new demo recorded from examples/server, a GIF in the
  repository (assets/demo.gif, regenerated by assets/demo.sh), since
  the asciinema image no longer loaded on GitHub. The Go Report Card
  badge is removed, the service no longer exists.

- .codecov.yml: threshold raised to 10%.

TESTS
-----
- errorpaths_test.go covers every rejection a flag kind or the parser
  can return; resetconfig_test.go and helporder_test.go pin the two
  fixes. Coverage: 96.7% to 99.4%.
